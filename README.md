# agentic_ai_learning

Projects for learning agentic AI development, managed as git submodules.

## Submodules

| Path | Repository |
|------|------------|
| [langchain_learning](./langchain_learning) | [DevangChauhan/langchain_learning](https://github.com/DevangChauhan/langchain_learning) |

## Setup

```bash
git clone --recurse-submodules git@github.com:DevangChauhan/agentic_ai_learning.git
```

## Updating a submodule

To update a submodule to its latest remote commit:

```bash
git submodule update --remote
```

Commit the resulting pointer change in this repo to pin the new version.
